# Logo assets (lpweb)

Canonical vectors/rasters for LAUNCHPAD lockup. Prefer these over any legacy base64-PNG favicon.

| File | Description |
|------|-------------|
| `logo-horizontal-color.svg` | Full lockup, brand purple `#75458E` |
| `logo-horizontal-color.png` | Approved raster lockup |
| `logo-horizontal-white.svg` | Full lockup, white |
| `logo-mark-rocket.svg` | Star + rocket mark only |

Web paths: `images/logo-launchpad.svg`, `images/logo-launchpad.png`, root `favicon.svg` (mark).

Header HTML uses the SVG lockup sitewide (see `scripts/cutover_www_and_logo.py` and `P0-PLAN.md`).
